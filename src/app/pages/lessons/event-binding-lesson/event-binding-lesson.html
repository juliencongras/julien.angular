🎯 Event Binding dans Angular

Le Event Binding permet d'écouter les événements du DOM (clic, saisie, survol...) et d'exécuter des méthodes côté composant.

Syntaxe standard : (event)="methode($event)". La variable spéciale $event transporte l'objet d'événement natif du DOM.
